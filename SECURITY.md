# Security policy

STOCKSIGNAL is an early demonstration prototype, not a production healthcare system. It has not been through a formal security assessment and should not be used to process confidential operational or patient data.

## Safe reporting

Please do not post credentials, patient details, real inventory files, private facility information, or exploit details that expose sensitive information in a public issue. For a general security concern, open an issue with a minimal synthetic reproduction and label it `security` where available. If the concern contains sensitive details, do not disclose those details in the public repository; seek a private contact route from the project maintainer before sharing them.

## Supported use

- Use synthetic data in public demos and tests.
- Keep secrets out of source code and Git history.
- Do not treat the prototype as an authorised clinical, dispensing, procurement, or stock-disposition system.
- Before any real-data pilot, complete appropriate security, privacy, access-control, retention, governance, and operational reviews.
